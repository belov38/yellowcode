# Yellowcode

Просмотрщик конфигураций и файловых баз 1С для macOS (Apple Silicon) и Windows. Только просмотр: приложение
ничего не меняет ни в конфигурации, ни в базе. Ранняя версия.

Скачать — на странице [Releases](https://github.com/belov38/yellowcode/releases).

## Установка

**macOS** — через Homebrew:

```sh
brew install --cask belov38/yellowcode/yellowcode
```

Или скачайте `.dmg`, откройте его и перетащите Yellowcode в «Программы».

Обновление:

```sh
brew update
brew upgrade --cask belov38/yellowcode/yellowcode
```

**Windows** — скачайте `Yellowcode-<версия>-windows-x64-setup.exe` и запустите. Если Windows покажет
предупреждение SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае».

## Как начать

Откройте файл конфигурации (`.cf`, `.cfe`, `.dt`) или копию файловой базы: файл `1Cv8.1CD` или папку базы.

- **Просмотр данных:** откройте базу, в дереве конфигурации щёлкните правой кнопкой по справочнику, документу
  или регистру и выберите «Открыть данные».
- **Консоль запросов:** меню «Сервис» → «Консоль запросов».

Работайте с копией базы, а не с рабочей. Устанавливать 1С не нужно.
