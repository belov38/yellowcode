Создать пользователя с пустым паролем и явно заданным набором ролей

Usage: yellowcode users create [OPTIONS] --name <NAME> <BASE>

Arguments:
  <BASE>  Каталог информационной базы или её файл 1Cv8.1CD

Options:
      --format <FORMAT>              Формат вывода; по умолчанию текст в терминале и JSON при перенаправлении [possible values: text, json]
      --platform-build <BUILD>       Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --name <NAME>                  Имя нового пользователя
      --full-name <FULL_NAME>        Полное имя; по умолчанию пустое [default: ""]
      --roles <ROLES>                UUID ролей текущей конфигурации через запятую; параметр можно повторять
      --clear-roles                  Явно назначить пустой набор ролей
      --show-in-list <SHOW_IN_LIST>  Показывать пользователя в списке выбора при входе (true или false) [default: true] [possible values: true, false]
  -h, --help                         Print help

Изменения записываются напрямую в файл базы. Сначала закройте базу в 1С и сделайте резервную копию: при сбое записи или питания база может быть повреждена. Автоматической резервной копии и восстановления нет.

Linux и macOS: установка пустого пароля. Windows: создание, изменение, установка пустого пароля и удаление пользователей.

Примеры:
  # Создать пользователя с пустым паролем и явно указанной ролью
  yellowcode users create base --name Оператор --roles 11111111-1111-1111-1111-111111111111

  # Изменить полное имя, сохранив пароль
  yellowcode users edit base Оператор --full-name "Сергей Иванов"

  # Удалить выбранного пользователя с подтверждением
  yellowcode users delete base Оператор --confirm

  # Очистить пароль выбранного пользователя с подтверждением
  yellowcode users clear-password base Администратор --confirm
