Выгрузить модули и макеты выбранной части конфигурации в каталог

Usage: yellowcode export [OPTIONS] --output <DIR> <SOURCE>

Arguments:
  <SOURCE>  Конфигурация: CF, DT, файл 1Cv8.1CD или каталог базы

Options:
      --output <DIR>                 Каталог выгрузки: создаётся или должен быть пуст
      --platform-build <BUILD>       Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --memory-limit <MEMORY_LIMIT>  Бюджет памяти на чтение конфигурации из DT; память самой модели расходуется сверх него
      --kind <KIND>                  Только объекты этих видов через запятую или повтором флага, например Справочник,Документ
      --path <PATH>                  Объект и всё под ним, например Справочник.Номенклатура, или один модуль по адресу из `module list`, например Справочник.Номенклатура.МодульОбъекта; флаг можно повторять
      --subsystem <SUBSYSTEM>        Только объекты подсистемы, полный (Подсистема.А.Подсистема.Б) или краткий (А.Б) путь; флаг можно повторять
      --format <FORMAT>              Формат вывода [default: text] [possible values: json, text]
  -h, --help                         Print help

Файлы лежат как в выгрузке конфигуратора: `Catalogs/Имя/Ext/ObjectModule.bsl`, `Catalogs/Имя/Forms/Форма/Ext/Form/Module.bsl`, `Catalogs/Имя/Templates/Макет/Ext/Template.*`; байты — как хранятся в источнике (BOM, CRLF). Каталог `--output` создаётся или должен быть пуст; в непустой каталог и поверх файла выгрузка не пишется. Последним пишется `manifest.json` (источник, область, числа и список файлов с размерами): он есть только у полной выгрузки. Если выгрузка оборвалась, stderr говорит об этом, код 1, манифеста нет. Пустая область — успех с пустым списком файлов. Описания объектов (XML) не выгружаются; внешние источники данных выгружаются, только когда в области объект `ExternalDataSource.Имя` целиком. Код возврата: 0 — успех, 1 — ошибка источника, области или каталога, 2 — ошибка аргументов.

Примеры:
  # Модули и макеты подсистемы «Пользователи» для поиска обычными средствами
  yellowcode export configuration.cf --subsystem СтандартныеПодсистемы.Пользователи --output users-src
  rg -n 'ПроверитьПрава' users-src

  # Все документы
  yellowcode export base --kind Документ --output docs-src
