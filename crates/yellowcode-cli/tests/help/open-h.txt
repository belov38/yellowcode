Открыть конфигурацию или информационную базу в установленном приложении

Usage: yellowcode open [OPTIONS] [SOURCE]

Arguments:
  [SOURCE]  Что открыть: CF, DT, файл 1Cv8.1CD или каталог базы

Options:
      --lang <LANG>                  Язык интерфейса [possible values: ru, en]
      --platform-build <BUILD>       Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --names <NAMES>                Готовая выгрузка конфигурации в XML для проверки модулей; без параметра приложение делает её само
      --memory-limit <MEMORY_LIMIT>  Бюджет памяти на чтение конфигурации из DT; память самой модели расходуется сверх него
      --smoke                        Проверочный запуск: открыть источник и выйти
  -h, --help                         Print help

Примеры:
  # Открыть конфигурацию
  yellowcode open configuration.cf

  # Открыть файловую базу с английским интерфейсом
  yellowcode open base --lang en

  # Открыть DT, выделив 3 ГиБ на чтение конфигурации
  yellowcode open backup.dt --memory-limit 3GiB
