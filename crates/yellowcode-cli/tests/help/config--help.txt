Конфигурация из CF, DT, 1CD или базы (только чтение): метаданные, модули, макеты, поиск, выгрузка

Usage: yellowcode config [OPTIONS] <COMMAND>

Commands:
  metadata  Метаданные конфигурации
  module    Модули: список, текст, процедуры и функции
  template  Макеты: список, содержимое, запросы схем компоновки данных
  grep      Поиск в текстах модулей, запросах схем компоновки данных и именах объектов, как grep
  export    Выгрузить модули и макеты выбранной части конфигурации в каталог
  help      Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --progress <MODE>         Ход работы в stderr: auto — строка на терминале, always — строки для журнала, never — без него (по умолчанию переменная YELLOWCODE_PROGRESS, иначе auto) [possible values: auto, always, never]
  -h, --help                    Print help

Источник — файл CF или DT, файл 1Cv8.1CD или каталог файловой базы. Источник только читается.

Примеры:
  # Справочники и документы конфигурации
  yellowcode config metadata tree configuration.cf --kind Справочник,Документ --depth 2 --format text

  # Процедуры и функции общего модуля
  yellowcode config module outline configuration.cf ОбщийМодуль.Пользователи

  # Схемы компоновки данных конфигурации
  yellowcode config template list configuration.cf --type dcs

  # Где вызывается процедура
  yellowcode config grep -F 'НачатьТранзакцию' configuration.cf --kind Документ

  # Модули и макеты документов в каталог
  yellowcode config export base --kind Документ --output docs-src

Справка по команде: yellowcode config <команда> --help
