Пользователи информационной базы и их карточки (без паролей и других секретов)

Usage: yellowcode users [OPTIONS] <COMMAND>

Commands:
  list            Список пользователей базы без служебной строки и секретов
  show            Карточка пользователя по имени или UUID; UUID нужен, если имена повторяются в разных областях данных
  create          Создать пользователя с пустым паролем и явно заданным набором ролей
  edit            Изменить только указанные поля пользователя, сохранив существующий пароль
  delete          Удалить выбранного пользователя с явным подтверждением
  clear-password  Очистить пароль выбранного пользователя с явным подтверждением
  help            Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
  -h, --help                    Print help

Linux и macOS: установка пустого пароля. Windows: создание, изменение, установка пустого пароля и удаление пользователей.

Примеры:
  # Список пользователей
  yellowcode users list base

  # Список в JSON-файл
  yellowcode users list base --format json > users.json

  # Карточка пользователя по имени (регистр не важен)
  yellowcode users show base Администратор

  # Карточка по UUID, если имена повторяются в разных областях данных
  yellowcode users show base 11111111-1111-1111-1111-111111111111

  # Создать пользователя с пустым паролем и явно указанной ролью
  yellowcode users create base --name Оператор --roles 11111111-1111-1111-1111-111111111111

  # Изменить полное имя, сохранив пароль
  yellowcode users edit base Оператор --full-name "Сергей Иванов"

  # Удалить выбранного пользователя с подтверждением
  yellowcode users delete base Оператор --confirm

  # Очистить пароль выбранного пользователя с подтверждением
  yellowcode users clear-password base Администратор --confirm
