Пользователи информационной базы и их карточки (без паролей и других секретов)

Usage: yellowcode users [OPTIONS] <COMMAND>

Commands:
  list  Список пользователей базы без служебной строки и секретов
  show  Карточка пользователя по имени или UUID; UUID нужен, если имена повторяются в разных областях данных
  help  Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
  -h, --help                    Print help

Примеры:
  # Список пользователей
  yellowcode users list base

  # Список в JSON-файл
  yellowcode users list base --format json > users.json

  # Карточка пользователя по имени (регистр не важен)
  yellowcode users show base Администратор

  # Карточка по UUID, если имена повторяются в разных областях данных
  yellowcode users show base 11111111-1111-1111-1111-111111111111
