Содержимое макета; для схемы компоновки данных — наборы, запросы, параметры, варианты

Usage: yellowcode template show [OPTIONS] <SOURCE> <TEMPLATE>

Arguments:
  <SOURCE>    Конфигурация: CF, DT, файл 1Cv8.1CD или каталог базы
  <TEMPLATE>  Путь макета из `template list`, например Отчет.СведенияОПользователях.Макет.ОсновнаяСхемаКомпоновкиДанных или ОбщийМакет.Печать

Options:
      --memory-limit <MEMORY_LIMIT>  Бюджет памяти на чтение конфигурации из DT; память самой модели расходуется сверх него
      --platform-build <BUILD>       Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --set <НАБОР>                  Набор данных схемы, чей запрос печатать; вместе с --query
      --query                        Печатать только текст запроса набора из --set
      --format <FORMAT>              Формат вывода [default: text] [possible values: json, text]
  -h, --help                         Print help

Макет — путь из `template list` (виды и слова `Макет`, `ОбщийМакет` — русские или английские). Схема компоновки данных показывается разделами: наборы данных с запросами, связи, ресурсы, вычисляемые поля, параметры, варианты. Отборы и другие значения схемы в тексте печатаются сырыми токенами схемы (`Equal`, `true`), а не русскими названиями. `--set НАБОР --query` печатает только текст запроса набора, как он записан в схеме, с завершающим переводом строки, если его нет. Текст запроса схемы содержит расширения языка компоновки данных (`{ГДЕ ...}`, `ХАРАКТЕРИСТИКИ`) и в общем случае не выполняется командой `yellowcode query`. Табличный документ показывается окном в 500 строк, при обрезке stderr говорит `yellowcode: shown rows 1–500 of N`; ячейки в тексте нумеруются с 1 (`R3C2`), а в `--format json` строки и колонки считаются с 0. Остальные макеты: текст или список файлов с размерами. `--format json`: объект с `schemaVersion: 1`, `path`, `type` и `view`; с `--query` — `path`, `dataSet`, `query`. Нет такого набора с запросом — ошибка со списком наборов, у которых запрос есть.

Примеры:
  # Схемы компоновки данных отчётов подсистемы
  yellowcode template list configuration.cf --type dcs --subsystem СтандартныеПодсистемы.Пользователи

  # Содержимое схемы: наборы, запросы, параметры, варианты
  yellowcode template show configuration.cf Отчет.СведенияОПользователях.Макет.ОсновнаяСхемаКомпоновкиДанных

  # Только текст запроса одного набора
  yellowcode template show configuration.cf Отчет.СведенияОПользователях.Макет.ОсновнаяСхемаКомпоновкиДанных --set Пользователи --query
