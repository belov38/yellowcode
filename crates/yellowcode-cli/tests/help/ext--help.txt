Расширение из файла CFE: свойства, объекты, модули, перехваты; только чтение

Usage: yellowcode ext [OPTIONS] <COMMAND>

Commands:
  info        Свойства расширения из файла CFE (только чтение)
  objects     Объекты верхнего уровня расширения CFE (только чтение)
  modules     Модули объектов расширения CFE (только чтение)
  intercepts  Перехваты методов в модулях расширения CFE (только чтение)
  help        Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --progress <MODE>         Ход работы в stderr: auto — строка на терминале, always — строки для журнала, never — без него (по умолчанию переменная YELLOWCODE_PROGRESS, иначе auto) [possible values: auto, always, never]
  -h, --help                    Print help

Примеры:
  # Свойства расширения
  yellowcode ext info extension.cfe --format text

  # Объекты верхнего уровня расширения
  yellowcode ext objects extension.cfe

  # Модули расширения, затем текст одного модуля
  yellowcode ext modules extension.cfe
  yellowcode ext modules extension.cfe --entry-id <entryId> --module <moduleKind>

  # Перехваты методов
  yellowcode ext intercepts extension.cfe --format text

Справка по команде: yellowcode ext <команда> --help
