Осмотреть резервную копию MS SQL Server или получить из неё CF, DT, 1CD

Usage: yellowcode bak [OPTIONS] <COMMAND>

Commands:
  inspect  Проверить структуру резервной копии без её восстановления
  convert  Сохранить CF, DT или 1CD из копии MS SQL Server: через сервер (--server) или, только CF, прямым чтением файла
  help     Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
  -h, --help                    Print help

Копия восстанавливается во временную базу на вашем SQL Server, результат выгружается, временная база удаляется; без --server CF читается прямо из файла BAK. CF: из полной копии, в том числе сжатой; на копиях типовых конфигураций записи как в выгрузке Конфигуратора, с --raw — как конфигурация хранится в базе. DT и 1CD: базы с управляемыми блокировками, в том числе типовых конфигураций на БСП с режимом совместимости 8.3.14–8.5.1, копии которых записаны платформой 8.5.1; что не поддерживается, команда отклоняет и называет причину; приёмка DT и 1CD текущей сборки не закончена (в ответе "experimental": true). Разностные, журнальные, шифрованные (в том числе TDE), составные и повреждённые копии отклоняются до восстановления. Проверено только на SQL Server 2022. Подробности: yellowcode bak convert --help и https://yellowcode.dev/guide/bak-convert/
