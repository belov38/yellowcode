Осмотреть резервную копию MS SQL Server или получить из неё CF, DT, 1CD (экспериментально)

Usage: yellowcode bak [OPTIONS] <COMMAND>

Commands:
  inspect  Проверить структуру резервной копии без её восстановления
  convert  Сохранить CF, DT или 1CD из копии MS SQL Server: через сервер (--server) или, только CF, прямым чтением файла
  help     Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
  -h, --help                    Print help

Экспериментально. Копия восстанавливается во временную базу на вашем SQL Server, результат выгружается, база удаляется. CF: из полной копии, в том числе сжатой; если конфигурацию обновляли динамически, результат такой же, как выгрузка Конфигуратора, с --raw — как конфигурация хранится в базе. DT и 1CD: базы с управляемыми блокировками, в том числе типовых конфигураций на БСП; базы с расширениями и политиками паролей отклоняются; копии с платформы 8.3.x не проверены, копия с другой строкой IBVersion отклоняется. Разностные, журнальные, шифрованные (в том числе TDE), составные и повреждённые копии отклоняются до восстановления. Проверено только на SQL Server 2022.
