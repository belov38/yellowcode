Yellowcode: конфигурации и информационные базы 1С

Usage: yellowcode [OPTIONS] [COMMAND]

Commands:
  open     Открыть источник в окне приложения (yellowcode-desktop)
  config   Конфигурация из CF, DT, 1CD или базы (только чтение): метаданные, модули, макеты, поиск, выгрузка
  ext      Расширение из файла CFE: свойства, объекты, модули, перехваты; только чтение
  ib       Данные файловой информационной базы: запросы, таблицы, пользователи, HTTP-сервис
  convert  Преобразовать файл в другой формат; исходный файл не меняется
  bak      Резервные копии MS SQL Server: осмотр, получение CF, DT, 1CD
  remote   Сервер 1С по сети, как тонкий клиент: сводка, метаданные, вызовы, модули, объекты, отчёты, запись, формы, печать
  help     Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>
          Точная версия эмулируемой платформы (не режим совместимости конфигурации)
          
          [default: 8.5.1.1529]

      --progress <MODE>
          Ход работы в stderr: auto — строка на терминале, always — строки для журнала, never — без него (по умолчанию переменная YELLOWCODE_PROGRESS, иначе auto)
          
          [possible values: auto, always, never]

  -h, --help
          Print help

  -V, --version
          Print version

Примеры:
  # Показать справочники и документы конфигурации
  yellowcode config metadata tree configuration.cf --kind Справочник,Документ --depth 2 --format text

  # Перехваты методов в расширении
  yellowcode ext intercepts extension.cfe --format text

  # Выполнить запрос к файловой базе (каталог с 1Cv8.1CD)
  yellowcode ib query base --text "ВЫБРАТЬ ПЕРВЫЕ 10 Наименование ИЗ Справочник.Контрагенты"

  # Прочитать первую страницу таблицы документа
  yellowcode ib table base Документ Счет --limit 100

  # Сохранить конфигурацию из DT в CF
  yellowcode convert backup.dt --to cf --output configuration.cf

  # Получить CF из резервной копии MS SQL Server
  yellowcode bak convert base.bak --to cf --output configuration.cf

  # Сводка сервера 1С при входе без пользователя
  yellowcode remote info http://server/base

  # Открыть конфигурацию в окне приложения
  yellowcode open configuration.cf
