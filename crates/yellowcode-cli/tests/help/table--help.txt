Прочитать одну страницу таблицы базы, при необходимости по индексу

Usage: yellowcode table [OPTIONS] <BASE> <KIND> <NAME>

Arguments:
  <BASE>  Каталог информационной базы или её файл 1Cv8.1CD (открывается только для чтения)
  <KIND>  Вид объекта метаданных, например Документ, Справочник, AccumulationRegister
  <NAME>  Имя объекта метаданных, например РеализацияТоваров

Options:
      --memory-limit <MEMORY_LIMIT>
          Общий бюджет памяти: auto или целое число байт с суффиксом B/KiB/MiB/GiB. Без лимита контейнера — 1GiB; конфигурациям уровня УНФ нужно --memory-limit не меньше 1792MiB, уровня ERP — около 3GiB
      --platform-build <BUILD>
          Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --cache-limit <CACHE_LIMIT>
          Предел кэша страниц; 0 отключает кэш
      --query-memory-limit <QUERY_MEMORY_LIMIT>
          Предел памяти на компиляцию, выполнение, пакет и временные таблицы запроса
      --result-memory-limit <RESULT_MEMORY_LIMIT>
          Предел памяти на хранимые результаты всех операторов запроса
      --response-limit <RESPONSE_LIMIT>
          Предел размера всего ответа, включая экранирование и схему
      --index <INDEX>
          Читать по этому индексу в порядке ключа; без него таблица читается в порядке хранения
      --eq <VALUE>
          Значение очередного поля индекса; повторять в порядке полей индекса
      --gt <VALUE>
          Нижняя граница (не включая) поля индекса после полей из --eq
      --gte <VALUE>
          Нижняя граница (включая) поля индекса после полей из --eq
      --lt <VALUE>
          Верхняя граница (не включая) поля индекса после полей из --eq
      --lte <VALUE>
          Верхняя граница (включая) поля индекса после полей из --eq
      --order <ORDER>
          Порядок ключа индекса (по умолчанию asc) [possible values: asc, desc]
      --posted <true|false>
          Только проведённые (true) или непроведённые (false) строки; для документов и журналов документов
      --deletion-mark <true|false>
          Только помеченные (true) или непомеченные (false) на удаление строки, и группы, и элементы
      --limit <LIMIT>
          Строк на странице [default: 1000]
      --cursor <CURSOR>
          Продолжить после страницы, которая вернула этот курсор; курсор действует, пока файл 1CD не менялся
      --format <FORMAT>
          Формат вывода; по умолчанию таблица в терминале и JSON при перенаправлении [possible values: table, json, csv]
  -h, --help
          Print help

Индекс читается так: --eq задаёт значения первых полей индекса по порядку, затем на следующее поле
можно задать диапазон (--gt или --gte снизу, --lt или --lte сверху). Даты: 2024-01-31 или
2024-01-31T12:00:00. Если указать несуществующий индекс, ошибка перечислит доступные индексы и их поля.
Курсор следующей страницы выводится в stderr строкой «yellowcode: next cursor: ...».

Примеры:
  # Первые 100 строк документа в порядке хранения
  yellowcode table base Документ Счет --limit 100

  # Документы за январь 2024 по индексу даты, от новых к старым
  # (первое поле индекса ByDocDate здесь — разделитель данных, поэтому --eq 0)
  yellowcode table base Документ Счет --index ByDocDate --eq 0 --gte 2024-01-01 --lt 2024-02-01 --order desc

  # Только проведённые документы без пометки удаления
  yellowcode table base Document Счет --posted true --deletion-mark false

  # Справочник в CSV
  yellowcode table base Справочник Контрагенты --format csv > contractors.csv

  # Следующая страница: та же команда и курсор из предыдущего вывода
  yellowcode table base Документ Счет --limit 100 --cursor <курсор>
--- stderr
