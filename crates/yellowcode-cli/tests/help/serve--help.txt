HTTP-сервис запросов и постраничного чтения таблиц (только чтение)

Usage: yellowcode serve [OPTIONS] <BASE>

Arguments:
  <BASE>  Неизменяемая копия базы: каталог или файл 1Cv8.1CD; открывается один раз только для чтения

Options:
      --memory-limit <MEMORY_LIMIT>
          Общий бюджет памяти: auto или целое число байт с суффиксом B/KiB/MiB/GiB. Без лимита контейнера — 1GiB; конфигурациям уровня УНФ нужно --memory-limit не меньше 1792MiB, уровня ERP — около 3GiB
      --platform-build <BUILD>
          Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --cache-limit <CACHE_LIMIT>
          Предел кэша страниц; 0 отключает кэш
      --query-memory-limit <QUERY_MEMORY_LIMIT>
          Предел памяти на компиляцию, выполнение, пакет и временные таблицы запроса
      --result-memory-limit <RESULT_MEMORY_LIMIT>
          Предел памяти на хранимые результаты всех операторов запроса
      --response-limit <RESPONSE_LIMIT>
          Предел размера всего ответа, включая экранирование и схему
      --listen <LISTEN>
          Адрес HTTP (контроль доступа и TLS — на стороне инфраструктуры) [default: 127.0.0.1:8080]
  -h, --help
          Print help

Сервис открывает базу один раз и не видит последующих изменений: запускайте его на неизменной копии
и перезапускайте после её обновления.

Примеры:
  # Сервис на 127.0.0.1:8080
  yellowcode serve base

  # Другой адрес и порт, 3 ГиБ памяти (конфигурации уровня ERP)
  yellowcode serve base --listen 0.0.0.0:9000 --memory-limit 3GiB

  # Запрос к сервису
  curl http://127.0.0.1:8080/query -H "Content-Type: application/json" \
    --data '{"text": "ВЫБРАТЬ &Число * 2 КАК Ответ", "params": [{"name": "Число", "repr": "21"}]}'

  # Страница таблицы справочника
  curl --get http://127.0.0.1:8080/table/Справочник \
    --data-urlencode "name=Контрагенты" --data-urlencode "limit=100"
