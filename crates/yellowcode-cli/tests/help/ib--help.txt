Данные файловой информационной базы: запросы, таблицы, пользователи, HTTP-сервис

Usage: yellowcode ib [OPTIONS] <COMMAND>

Commands:
  query  Выполнить запрос к информационной базе (только чтение)
  table  Прочитать одну страницу таблицы базы, при необходимости по индексу
  users  Пользователи информационной базы и их карточки (без паролей и других секретов)
  serve  HTTP-сервис запросов и постраничного чтения таблиц (только чтение)
  help   Print this message or the help of the given subcommand(s)

Options:
      --platform-build <BUILD>  Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --progress <MODE>         Ход работы в stderr: auto — строка на терминале, always — строки для журнала, never — без него (по умолчанию переменная YELLOWCODE_PROGRESS, иначе auto) [possible values: auto, always, never]
  -h, --help                    Print help

База — каталог файловой базы с 1Cv8.1CD или сам файл 1Cv8.1CD.

Примеры:
  # Выполнить запрос (только чтение)
  yellowcode ib query base --text "ВЫБРАТЬ ПЕРВЫЕ 10 Наименование ИЗ Справочник.Контрагенты"

  # Прочитать первую страницу таблицы документа
  yellowcode ib table base Документ Счет --limit 100

  # Список пользователей базы
  yellowcode ib users list base

  # HTTP-сервис запросов на 127.0.0.1:8080
  yellowcode ib serve base

Справка по команде: yellowcode ib <команда> --help
