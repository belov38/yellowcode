Текст модуля, целиком, по строкам или одна процедура

Usage: yellowcode config module show [OPTIONS] <SOURCE> <MODULE>

Arguments:
  <SOURCE>  Конфигурация: CF, DT, файл 1Cv8.1CD или каталог базы
  <MODULE>  Путь модуля из `yellowcode config module list` или объект с единственным модулем, например Справочник.Пользователи.МодульОбъекта

Options:
      --memory-limit <MEMORY_LIMIT>  Бюджет памяти на чтение конфигурации из DT; память самой модели расходуется сверх него
      --platform-build <BUILD>       Точная версия эмулируемой платформы (не режим совместимости конфигурации) [default: 8.5.1.1529]
      --lines <A:B>                  Только строки с A по B (с единицы); `A:` — до конца модуля
      --progress <MODE>              Ход работы в stderr: auto — строка на терминале, always — строки для журнала, never — без него (по умолчанию переменная YELLOWCODE_PROGRESS, иначе auto) [possible values: auto, always, never]
      --procedure <ИМЯ>              Только процедура или функция с этим именем, с комментариями и директивами над ней
  -n, --line-numbers                 Начинать каждую строку с её номера в модуле
      --format <FORMAT>              Формат вывода [default: text] [possible values: json, text]
  -h, --help                         Print help

Примеры:
  # Модули справочников подсистемы «Пользователи»
  yellowcode config module list configuration.cf --kind Справочник --subsystem СтандартныеПодсистемы.Пользователи

  # Модуль объекта справочника
  yellowcode config module show configuration.cf Справочник.Пользователи.МодульОбъекта

  # Одна процедура с номерами строк
  yellowcode config module show configuration.cf Справочник.Пользователи.МодульОбъекта --procedure ПередЗаписью -n

  # Строки 100–160 модуля формы
  yellowcode config module show configuration.cf Справочник.Пользователи.Форма.ФормаЭлемента.МодульФормы --lines 100:160

  # Процедуры и функции общего модуля
  yellowcode config module outline configuration.cf ОбщийМодуль.Пользователи
